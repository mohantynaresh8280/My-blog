# Simple Blog (REST + EJS)
## Features
- Full CRUD: create, read, update, delete posts
- RESTful routes (`GET`, `POST`, `PUT`, `DELETE` via `method-override`)
- Server-rendered EJS views with a clean, minimal blog theme

Getting started
First, run the development server:

npm install  
npm start

Then open http://localhost:3000 with your browser to see the result.
